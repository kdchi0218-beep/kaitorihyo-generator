# とんとん 買取表ジェネレーター 取扱説明書

買取表（PSA10等）の画像を、毎日のExcelデータから自動生成するツールです。
URL: https://tonton-kaitori-generator.vercel.app/
（アプリ内の「使い方」ボタンからも要約版が見られます）

---

## 1. ログイン・店舗

- 店舗ごとに発行されたメールアドレス＋パスワードでログイン
- 管理者（d.kato）は全店舗を切り替え可能。店舗ユーザーは自店のみ
- 定番リスト・テンプレートは**同じ店舗のアカウント間で共有**されます

## 2. 毎日の基本の流れ

1. 入力タイプを選び、その日のExcelファイルを画面にドラッグ
   - **とんとん形式**（初期選択）: `🐽トントン_買取表管理_v2` から出力したポケモン/ワンピースの単一シートを読み込み
   - **Vault形式**: 1ファイルで5ジャンル（ポケモン/ポケモン旧裏/ワンピース/遊戯王/ヴァイス）を一括読み込み
   - 選んだ入力タイプは次回利用時も保持されます
2. ジャンルタブを選ぶ
3. 定番リストを選んで**「適用」** → 登録した順番・その日の価格で買取表に並ぶ
4. 必要ならカードを追加・削除・並べ替え・価格修正
5. **「PNG保存」**または**「CSV出力」**で出力（画像は1ページ=列×行を超えると自動で複数ページ→ZIP）

## 3. カード選択・並べ替え

| 機能 | 説明 |
|---|---|
| 選択中タブ | 買取表に載るカード。ドラッグ or ▲▼で並べ替え |
| ☑複数まとめて移動 | 複数の行にチェック→チェックした行のどれかをドラッグすると、ブロックごとまとめて移動（相対順序は維持） |
| 未選択タブ | クリックで1枚追加。☑複数チェック→「チェックしたN枚を追加」で一括追加 |
| プレビュー直接並べ替え | **プレビュー上のカードを直接ドラッグ&ドロップ**で位置変更（ページまたぎOK・ドラッグ中の青枠等は出力画像に入らない） |
| どのリストにも入っていないカードのみ表示 | タブ直下のチェック。**新しくExcelに追加されたカードの発見用**。該当カードには「リスト外」バッジ |
| ダブルクリック編集 | カード名・価格を直接編集。価格は数字 or「要相談」等の文字もOK |
| 手動価格の保護 | 手動入力した価格は掛け率を変えても上書きされない |

## 4. 定番リスト

毎日使うカードの並びを保存しておく機能。**照合は「型番＋種別＋カード名（遊戯王はレアリティも）」の完全一致**なので、同じ型番の別カードに化けることはありません。

| ボタン | 動作 |
|---|---|
| 適用 | リストを今日の価格で選択中に展開（保存順を維持・在庫切れはスキップ） |
| 中身を編集 | 追加（検索）／削除／並べ替え（**ドラッグ・▲▼・☑複数チェックでまとめて移動**）。保存すると即プレビューに反映 |
| 選択中を追加 | 今の選択のうちリストに無いカードだけを差分追加（既存は消えない） |
| 選択中で上書き | リストを今の選択で丸ごと置き換え（確認あり） |
| ＋ Excelに無いカードを手入力で追加（事前登録） | 下記6章 |
| CSV | リストの中身（保存順・型番・今日の在庫状況・前回価格）をCSVでダウンロード |
| 他店へ送信 | リストを別店舗にコピー（店舗を選んで送信） |
| リスト削除 | このリストを削除（確認あり） |

- リストには毎回の適用時に**画像URLと最新価格が自動保存**されます（発注が無い日の表示に使用）
- 編集中にジャンル・店舗・リストを切り替えると「変更を保存して編集を完了しますか？」を確認

## 5. 発注が来てないカードの表示（前回価格）

- **「発注が来てないカードも表示する」**チェックで即切替（適用ボタン不要）
  - ON: 発注なしカードがリスト順の位置に表示される／OFF: 発注なし分だけ消える
  - 手動で足したカード・並べ替えは壊しません
- 価格 = **前回読み込み価格**（最後に発注があった日の基準価格）に今日の掛け率・金額帯・端数を適用した金額
- プレビューのカード左上に**「前回価格」バッジ**（画面のみ。**出力画像には印字されません**）
- 価格をダブルクリックで修正すると**リストに自動保存**されます。全ジャンルで、編集した当日は「前回価格」バッジが消え、翌日も発注なしなら同じ金額でバッジが再表示されます。発注が再び来たらExcelの実価格に自動で戻ります
- 一度も発注データに載ったことがないカードは「-」表示（手動入力可）

## 6. Excelに無いカードの事前登録

新弾などまだ発注データに無いカードを先にリストへ登録できます。

1. 定番リストの緑の点線ボタン**「＋ Excelに無いカードを手入力で追加（事前登録）」**を押す（1クリックでフォームが開く）
2. カード名（必須）／型番／種別／レアリティ（遊戯王のみ）／表示価格（任意）／画像URL（任意）を入力
3. 「この内容でリストに追加」→ 最後に**「この内容で保存」**
4. 発注なし表示ONで、入力した画像・価格のカードとして買取表に出せます
5. 後日Excelに載ったら、自動で実カード・実価格に切り替わります

> ⚠ カード名・型番は**Excelの表記と完全一致**させてください。一致しないと別カード扱いになります。

## 7. カード名変更の警告

Excel側でカード名が変わると、そのカードは照合できず在庫切れ扱いになります。その際、適用時に黄色い警告が出ます：

- 「保存名 → 今日の名前」の候補を表示（同じ型番・種別で名前だけ違うカードを検出）
- **「この名前に更新」**でリストの名前・画像・価格を新カードに引き継ぎ
- 本当に完売しただけのカードには警告は出ません／型番なしカードは検知対象外

## 8. テンプレート（見た目・価格設定の保存）

- 「テンプレート」ゾーンで、見た目＋買取価格ルール一式を名前を付けて保存
- 読込／上書き／名前変更／詳細（価格ルールの中身確認）／削除／**他店へ送信**
- 「設定をデフォルトに戻す」で初期化
- ジャンルごとに別管理（ポケモン用・遊戯王用など）

## 9. 見た目・価格の設定

- **買取価格ルール**: 基本の掛け率%（±）／定額調整（±円）／端数の単位（100円等）と丸め方向（繰り上げ/四捨五入/切り捨て）
- **金額帯ごとのルール**（例: 1万〜10万円は-5%。範囲が重なると警告表示）: 帯ごとに掛け率・定額に加え、**端数の単位・丸め方向も個別指定可**。未指定の項目は上の「基本」に従う
- キャンバスサイズ／背景（色・画像）／ヘッダー（タイトル・ロゴ）／グリッド（列×行・カードサイズ・余白）／カード枠／PSAバッジ／レアリティ表示（遊戯王・略称や表示ON/OFF設定可）／カード名／型番／価格文字（色・縁取り・背景）／更新日時（位置・px指定可）／フッター
- 各スライダーは **−/＋ボタン**で1ずつ微調整できます

## 10. 出力

- 「PNG保存」: プレビューと同じ画像を高解像度（2倍）でダウンロード
- 「CSV出力」: **現在画面に表示中の買取表だけ**を、表示順・価格・発注状況・前回価格つきのExcel向けCSVでダウンロード。定番リスト横の「CSV」は、リストに保存された内容・今日の在庫状況を確認する別機能です
- 複数ページは自動でZIPにまとめて保存
- 画面専用の表示（「前回価格」バッジ等）は出力に含まれません

## 11. 困ったとき

| 症状 | 対処 |
|---|---|
| 画面上部に「新しいバージョンがあります」 | **必ず「今すぐ更新」を押す**（古いままだと不具合が直りません） |
| 表示がおかしい | Cmd+Shift+R（Win: Ctrl+F5）で強制再読み込み |
| リストの中身を確認したい | 「CSV」ボタンでダウンロードしてExcelで確認 |
| 不具合を報告したい | サイドバー下の **vから始まるバージョン番号**＋スクリーンショット＋操作手順を添える |
