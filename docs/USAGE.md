# とんとん 買取表ジェネレーター 使い方

**対象:** とんとん各店舗のスタッフ・管理者

**URL:** <https://tonton-kaitori-generator.vercel.app/>
**最終更新:** 2026-08-23

この手順書だけで、引継ぎや口頭説明なしに「当日のExcelを読む → 買取表を整える → 画像を出力する」まで行えます。Vaultの既存ジェネレーターは別のまま、このサイトはとんとん運用の総合版です。

## 3分で作る（毎日の最短手順）

1. 決められたPC・ブラウザのプロフィールでサイトを開き、メールアドレスとパスワードで**「ログイン」**します。
2. 左の**「データ取得」**で**「とんとん形式」**または**「Vault形式」**を選び、当日の `.xlsx` / `.xls` を**「Excelをクリック / ドラッグ&ドロップ」**へ入れます。
3. 必要なジャンルタブを選び、そのジャンル用テンプレートを**「読込」**します。価格ルールと見た目が正しいか確認します。
4. **「定番リスト（この店舗内）」**からいつものリストを選んで**「適用」**し、必要ならカードを追加・削除・並べ替えます。
5. 左下でPNGまたはJPEGを選び、**「PNG出力」**または**「JPEG出力」**を押します。複数ページはZIPで保存されます。

> **毎回確認:** 現在の見た目・価格ルールはジャンル別ではなく、店舗で1つの共有設定です。ジャンルを替えたら、必ずそのジャンル用テンプレートを**「読込」**してから出力してください。

定番リストがない場合は、Excelを読込後にカードを選び、リスト名を入力して**「作成」**→**「選択中で上書き」**を押してください。

## 使う前に準備するもの

| 必要なもの | 内容 |
|---|---|
| 利用PC・ブラウザ | 初回ログインしたブラウザプロフィールに固定されます。共有PCなら指定された同じブラウザ・同じプロフィールを使います。 |
| アカウント | 管理者が発行したメールアドレスとパスワード（初期パスワードは12文字以上）。 |
| 当日のExcel | `.xlsx` または `.xls`。CSVは直接は読めません。 |
| 管理体制 | 管理者を最低2人置きます。片方のPC交換時に、もう一人がブラウザ固定を解除するためです。 |

## ログインと初回ブラウザ固定

アカウントは、**最初に正しいパスワードでログインした1つのブラウザプロフィールだけ**で使えます。パスワードを知っていても別PCへ自由に持ち出せない、安全のための仕組みです。

- 同じPC・同じブラウザ・同じプロフィールなら、ログアウト後もログインできます。
- 別PC、別ブラウザ、別Chromeプロフィール、シークレットウィンドウ、Cookie削除後は別ブラウザ扱いです。
- ログアウトしても固定は解除されません。
- 初回ログインは、今後も使い続けるブラウザで行います。シークレットウィンドウでは行いません。
- 新しいPCへ移すには、先に管理者が解除し、その後に新しいブラウザでログインします。

「このアカウントは別のブラウザに固定されています」と表示された場合、更新やパスワードの入れ直しでは直りません。管理者へ**「ブラウザ登録を解除」**を依頼してください。

### 読み込み手順

1. **「とんとん形式」**または**「Vault形式」**を選びます。
2. 枠をクリックしてExcelを選ぶか、ファイルを枠へドラッグします。
3. 緑色の完了表示で、必要ジャンルの件数が出ていることを確認します。
4. ジャンルタブを押して内容を確認します。

読込結果が0件または `—` の対象ジャンルは、そのジャンルの現在の読込データ・選択中カードも空になります。前回データの誤出力を防ぐための動作です。Vault形式の `—` は、シートがない、シートが空、必要なヘッダーを読めない場合にも表示されます。必要な5ジャンルのシートを1ファイルに揃え、形式を間違えたときは正しい形式へ切り替えて読み直してください。

### 1ジャンルだけ読む／スプレッドシートから読む

- **「［ジャンル名］だけ単体で読み込む」**では、現在のジャンルだけを読み込みます。ジャンル名を含むシートを優先し、なければ先頭シートを使います。この機能はVault形式の列構成用です。
- **「スプシURLから取得（［ジャンル名］・任意）」**では、対象タブのGoogleスプレッドシートURL（`#gid=`付き）を貼り、**「更新（取得）」**を押します。この機能もVault形式の列構成用です。
- スプシはサーバーがログインなしで取得します。共有を**「リンクを知っている全員が閲覧可」**または公開にしてください。リンクを持つ人が内容を見られるため、社内承認済みの専用シートだけを使い、秘密情報は置かないでください。
- 読み込み直すと、そのジャンルの読込一覧と選択中カードが新しい内容に置き換わります。
- 誤読込は**「このジャンルのデータをクリア」**で、そのジャンルの読込データと選択中カードを消せます。

## 毎日の作業を最後まで行う

### 1. 当日のExcelを読み込む

前日の画面をそのまま使わず、必ず当日のExcelを読込みます。読込後に正しいジャンルを選び、件数を確認します。

### 2. ジャンル用テンプレートを読み込む

1. 上部で作成するジャンルを選びます。
2. **「テンプレート（［ジャンル名］）」**から、そのジャンルで使うテンプレートの**「読込」**を押します。
3. **「⚙ 見た目・価格の設定」**で掛け率・端数・表題を確認し、右プレビューも確認します。

現在の見た目・価格ルールは、店舗で1つを共有しています。ジャンルタブを押すだけでは設定は切り替わりません。テンプレートの**「読込」**は現在店舗の共有設定を置き換え、約800ms後に自動保存されます。

### 3. 定番リストを適用する

1. **「定番リスト（この店舗内）」**でリスト名を選びます。
2. 通常は**「適用」**を押します。
3. 保存順のまま、今日のExcelにあるカードが**「選択中」**へ並びます。Excelにないカードは通常は外れます。
4. 完了メッセージと右プレビューを確認します。

### 4. 発注が来ていないカードも出す

継続掲載したいカードが今日のExcelにない場合に使います。

1. リストを選びます。
2. **「発注が来てないカードも表示する（画像つき・前回読み込み価格で表示→必要なら手動修正）」**をオンにします。
3. 発注なしカードもリスト順の位置に表示されます。最後にExcelで読めた元価格へ、現在の価格ルールを適用した価格です。
4. 画面では**「前回価格」**バッジが出ますが、PNG/JPEGには入りません。
5. 価格を直すなら、カードの価格をダブルクリックし、数値または `要相談` などの文字を入力してEnterまたはフォーカス移動で確定します。発注なしカードへの手入力は定番リストへ保存され、翌日も優先表示されます。文字は文字のまま残り、数値は翌日に「前回価格」として表示される場合があります。

一度もExcelに出たことのない事前登録カードは、価格未入力なら `-` です。チェックを外すと発注なしカードだけをプレビューから外します。

### 5. カードを追加・削除・編集・並べ替える

**「未選択」**は候補、**「選択中」**は出力対象です。

| やりたいこと | 操作 |
|---|---|
| 1枚追加 | **「未選択」**のカード行をクリック。 |
| 複数追加 | 未選択カードへチェックを付け、**「チェックしたN枚を追加」**を押す。 |
| 1枚削除 | **「選択中」**の行右端の `×`。 |
| 全部追加／外す | **「全選択」**／**「全解除」**。 |
| 順番を変える | 選択中をドラッグ、または `▲` `▼`。プレビュー上のカードをドラッグしてもよい。 |
| まとめて移動 | 選択中で複数にチェックを付け、そのうち1枚をドラッグ。順序を保ったまま移動します。 |
| 探す・絞る | 「カード名検索...」、種別、カテゴリ、価格あり、並び順を使う。 |
| 新着を探す | **「どの定番リストにも入っていないカードのみ表示」**をオン。`リスト外`が候補です。 |
| 名前を直す | カード名をダブルクリックして編集。 |
| 価格を直す | 価格をダブルクリック。数字のほか `要相談` 等の文字も入力できます。 |

手入力した**数値価格**は、自動の掛け率・丸め再計算で上書きされません。`要相談` などの**文字価格**も表示用の上書きとして残り、自動計算した数値より優先して表示されます。元の自動計算へ確実に戻すには、当日のExcelを読み直してください。カードを一度外して再追加するだけでは戻りません。

### 6. 出力前の確認

- 店舗名・ジャンルが正しいか。
- プレビューと左下の枚数／ページ数が正しいか。
- `-`、`要相談`、前回価格の扱いが意図どおりか。
- ページをまたいで背景・ロゴ・カード順が正しいか。

### 7. PNG/JPEG/CSVを保存する

1. 左下で**PNG**または**JPEG**を選びます。
2. **「PNG出力」**または**「JPEG出力」**を押します。
3. 1ページは画像、複数ページはZIPがブラウザのダウンロード先へ保存されます。
4. 表でも確認するなら**「CSV出力」**を押します。現在の選択中カードのみを、表示順・型番・種別・レアリティ・買取価格・発注状況・前回価格付きで保存します。

## 価格ルールと端数処理

**「⚙ 見た目・価格の設定」**→**「買取価格ルール（掛け率・端数）」**で設定します。

```text
表示価格 = （Excelの元価格 × (1 + 掛け率 ÷ 100) + 定額調整）を端数処理
```

| 項目 | 内容 |
|---|---|
| 基本の掛け率 | `+` は上乗せ、`-` は値引き。 |
| 基本の定額調整 | 円単位の加減算。 |
| 端数の単位 | 1、10、100、500、1,000、5,000、10,000、50,000円。 |
| 丸め方向 | 繰り上げ、四捨五入、切り捨て。 |
| 金額帯ごとのルール | 指定した元価格の範囲だけ、基本ルールを上書き。空欄項目は基本に従います。 |

例: 元価格185,498円、掛け率-2.7%、100円単位で繰り上げなら180,500円です。金額帯は重ねないでください。重なった場合は先にある帯が優先され、警告が出ます。

## 定番リストの作り方・育て方

定番リストは「毎日載せるカード」と「掲載順」を、**店舗内・ジャンル別**に共有保存する機能です。

### 初めて作る

1. Excelを読み込み、**「未選択」**から必要なカードを選びます。
2. **「選択中」**を掲載順に整えます。
3. 「新しいリスト名（例: 定番）」に名前を入れ、**「作成」**を押します。
4. 作ったリストを選び、**「選択中で上書き」**を押して確定します。

| ボタン | 内容 |
|---|---|
| **適用** | 今日のExcelの価格・画像で、保存順に展開します。Excelにないカードは通常スキップ。 |
| **中身を編集** | リスト自体を検索追加・削除・ドラッグ・`▲▼`・複数移動で編集し、**「この内容で保存」**で確定。 |
| **選択中を追加** | 選択中のうちリストにないカードだけを追加。既存は消えません。 |
| **＋ Excelに無いカードを手入力で追加（事前登録）** | 未入荷カードを事前にリストへ登録。 |
| **選択中で上書き** | リスト全体を現在の選択中で置換。既存内容は消えます。 |
| **CSV** | リストの保存順、今日の在庫解決、解決先価格、前回元価格をCSVで確認。 |
| **他店へ送信** | 他店へアクセスできる管理者がリストを別店舗へコピー。送信元は残ります。 |
| **リスト削除** | この店舗・このジャンルのリストを削除。元に戻せません。 |

照合は商品ID、なければ**型番＋種別＋カード名**、遊戯王ではレアリティも使います。Excelで表記が変わると別カードになる場合があります。

### Excelにないカードを事前登録する

1. **「＋ Excelに無いカードを手入力で追加（事前登録）」**を開きます。
2. **カード名（必須）**、型番、種別を入れます。遊戯王では必要に応じてレアリティも入れます。
3. 必要なら表示価格と `https://` の画像URLを入れます。
4. **「この内容でリストに追加」**を押します。
5. 編集画面下の**「この内容で保存」**を押します。

後日Excelに同じカードが載り、名前・型番・種別（遊戯王はレアリティも）が一致すれば実データへ切り替わります。

### カード名が変わった場合

**「適用」**時に、同じ型番・種別なのに名前だけ異なる候補があれば黄色い警告が出ます。本当に同じカードなら候補の**「この名前に更新」**を押してください。リストの名前・画像・価格基準を新名称へ引き継ぎます。単なる在庫なしなら更新しません。

## テンプレートとデザイン

テンプレートは、ジャンルごとの見た目と価格ルールを一式で保存します。一方、画面に現在反映されている見た目・価格ルールは、**ジャンル別ではなく店舗で1つの共有設定**です。

1. **「テンプレート（［ジャンル名］）」**を開きます。
2. 現在の設定を保存するには名前を入力して**「保存」**。
3. 既存を使うには**「読込」**。今の設定で更新するには**「上書」**。
4. **「詳細」**で価格ルール、**「名前」**で名称、**「削除」**で削除を行えます。
5. 他店へアクセスできる管理者が他店へ渡すときは、**「送信」**→送信先選択→**「この店舗に送信」**です。通常の店舗ユーザーには送信先が表示されません。

テンプレートは店舗内共有、ジャンル別です。ポケモンで保存したテンプレートはワンピースには表示されません。ジャンルタブを切り替えただけでは現在設定は切り替わらないため、必ず該当テンプレートを**「読込」**してください。

| 設定項目 | 主な内容 |
|---|---|
| キャンバス・出力設定 | 画像サイズ、空き枠。 |
| 背景設定 | 背景色・背景画像・合わせ方。 |
| ヘッダー・ロゴ設定 | 表題、ロゴ、位置・大きさ。 |
| カードグリッド設定 | 列数・行数・余白・カード寸法。列×行を超えると複数ページ。 |
| カード枠／PSAロゴ | 枠線・背景・影、PSAバッジ。 |
| レアリティ表示（遊戯王） | 表示、略称、非表示設定。 |
| カード名／価格／フッター | 文字、円記号、更新日時、注意書き。 |

設定変更、テンプレートの**「読込」**、**「設定をデフォルトに戻す」**は、現在店舗の共有設定を置き換え、約800ms後に自動保存されます。同じ店舗で同時に編集すると、最後に保存された内容が優先されます。作業前に声を掛け合い、店舗やブラウザを切り替える前・画面を閉じる前は少し待ってください。

**「設定をデフォルトに戻す」**を押しても保存済みテンプレート自体は消えませんが、店舗の現在設定は初期値へ戻って共有されます。必要なら直前にテンプレートを別名保存してください。背景・ロゴには軽量化した小さめのPNG/JPEG/WebPを使い、保存後は画面を再読み込みして表示を確認してください。

## 店舗・ユーザー・ブラウザ固定の管理（管理者向け）

管理者は上部の**「店舗・ユーザー管理」**を開きます。管理者は全店舗を操作できます。通常ユーザーは割り当てられた自店舗のみです。

### 店舗とアカウントを作る

1. **「店舗を追加」**に店舗名を入れ、**「追加」**。
2. 店舗カードにメールアドレスとパスワードを入れます。**「生成」**で16文字のパスワードを作れます。
3. **「アカウント発行」**。
4. ID（メール）とパスワードを利用者へ安全に渡し、指定PC・ブラウザで初回ログインするよう伝えます。

この画面から発行できるのは通常の店舗ユーザーです。管理者の追加・昇格、忘れたパスワードの再設定は画面からできないため、運営担当へ依頼してください。店舗が未割当のユーザーは、ログインしても買取表を操作できません。

### PC交換・Cookie削除時の復旧

1. **別の管理者**がログインします。現在ログイン中の管理者自身は自分を解除できません。
2. **「ブラウザ固定の管理」**で対象者を探します。必要なら**「再読込」**。
3. 対象行の**「ブラウザ登録を解除」**を押します。
4. 理由（例: `PC交換・ブラウザ変更`）を入力し、確認します。
5. 利用者が新しいPC・ブラウザプロフィールでパスワードログインします。最初にログインしたその環境へ固定されます。

解除理由と実施者は監査用に記録されます。解除後、旧ブラウザは使えません。管理者を1人だけにしないでください。

### 削除時の注意

**「店舗を削除」**は、その店舗の現在設定、メンバー紐付け、定番リスト、テンプレートをすべて削除します。元に戻せません。ログイン用ユーザーそのものは残りますが、店舗未割当になり使用できません。責任者が削除対象と必要な退避を確認してから実施してください。

## 何が共有・保存されるか

| データ | 保存・共有範囲 |
|---|---|
| 現在の見た目・価格ルール | クラウド保存。**同一店舗内で1つを共有**し、ジャンル別ではありません。変更は約800msで自動保存されます。 |
| テンプレート | クラウド保存。**同一店舗内**で共有し、ジャンル別です。読込むと現在の共有設定を置き換えます。 |
| 定番リスト、事前登録、発注なしカードの手動価格・文字 | クラウド保存。**同一店舗内**で共有し、ジャンル別です。 |
| 当日読込んだカード一覧・選択中カード | 使用ブラウザ内のローカル保存が中心。別PC・別プロフィールへ自動共有されません。毎日Excelを読込んでください。 |
| 店舗切替・ジャンル・サイドバー幅 | 使用ブラウザ内に保存。 |
| 背景・ロゴ画像 | 店舗設定・テンプレートの一部として保存され、権限のある利用者が使えます。 |
| 出力PNG/JPEG/ZIP/CSV | 利用PCのダウンロード先。サイト上で完成画像を一覧保管する機能はありません。 |

他店へアクセスできる管理者がデータを渡す場合は、定番リストの**「他店へ送信」**またはテンプレートの**「送信」**を使います。通常の店舗ユーザーには送信先が表示されません。店舗を切り替えただけでは他店データは混ざりません。

## 更新・復旧・トラブルシューティング

| 症状 | まず行うこと |
|---|---|
| 別のブラウザに固定されている | 管理者に解除を依頼。解除後、使うブラウザでログイン。 |
| 管理者自身が固定で入れない | もう一人の管理者に解除を依頼。1人しかいない場合は運営担当へ連絡。 |
| ログインできない | メール・パスワードを確認。固定表示でなければ管理者にアカウント発行状況を確認。 |
| パスワードを忘れた／管理者を追加したい | 画面内に再設定・管理者昇格機能はありません。運営担当へ依頼。 |
| Excelを選べない | `.xlsx` / `.xls` を使う。CSVはExcel形式で保存し直す。 |
| カード名列が見つからない | ヘッダーを先頭行にし、「カード名」「名称」「商品名」等を確認。 |
| 目的ジャンルが `—` | Vaultのシート名、空シート、カード名ヘッダーを確認。`—` になったジャンルの旧データは消えます。修正後に再読込。 |
| スプシURLから取得できない | Googleスプレッドシートの対象タブURLに `#gid=` があるか、共有が「リンクを知っている全員が閲覧可」または公開かを確認。 |
| とんとんExcelのジャンルが違う | シート名・ジャンル列・型番を確認し、内容を直して「とんとん形式」で読み直す。判定できない場合はポケモン扱いになります。 |
| 価格が違う | 正しいジャンル用テンプレートを読込んだか、掛け率・金額帯・丸め・手動の数値／文字価格を確認。自動へ戻すならExcelを再読込。 |
| リスト適用でカードが出ない | 今日のExcelにないか、名前・型番等が不一致。リストCSV、発注なし表示、名前更新候補を確認。 |
| 新弾がリストにない | 「リスト外のみ表示」で探し、「選択中を追加」か「中身を編集」で追加。 |
| 画像がない／違う | Excelまたは事前登録の画像URLを確認。`https://` URLを使う。 |
| 画面がおかしい／反映されない | 上部に更新案内があれば**「今すぐ更新」**。なければ強制再読み込み（Mac: Cmd+Shift+R、Windows: Ctrl+F5）。Cookie削除はしない。 |
| 画像出力に失敗 | 少し待って再実行。続く場合はCSVを保存し、スクリーンショットとバージョン番号を添えて連絡。 |
| アカウントには入れるが使えない | 店舗未割当の可能性。管理者に確認。 |

## 日々のチェックリスト

### やること

- 当日のExcelを読み込み、ジャンル用テンプレートを**「読込」**して価格ルールを確認してから、定番リストを**「適用」**する。
- 出力前に店舗名、ジャンル、枚数、プレビューを確認する。
- 新着は「リスト外のみ表示」で確認し、必要なものだけリストへ追加する。
- 大きなデザイン変更前にテンプレートを別名保存する。
- PC変更・ブラウザ変更前に管理者へ相談する。
- 不具合報告に左上の `v...` バージョン番号を添える。

### やらないこと

- パスワードや固定ブラウザを他人へ貸さない。
- Cookie削除、シークレット、別プロフィールで安易にログインしない。
- **「選択中で上書き」**、**「上書」**、**「リスト削除」**、**「店舗を削除」**を内容確認なしに押さない。
- 同じ店舗の見た目・価格設定を複数人で同時編集しない。最後に保存された内容で上書きされます。
- Vaultの5ジャンルExcelをとんとん形式で、またはとんとん単一シートをVault形式で読まない。
- 前日の画面だけで出力しない。

## 用語集

| 用語 | 意味 |
|---|---|
| 買取表 | 店頭・SNS等へ出す、カードと買取価格の画像。 |
| 選択中 | 現在の買取表へ載る出力対象カード。 |
| 未選択 | 読込済みだが現在は出力しない候補カード。 |
| 定番リスト | 毎日使うカードと掲載順を店舗内共有するリスト。 |
| 事前登録 | Excelにまだないカードを先に定番リストへ入れること。 |
| 発注なしカード | 今日のExcelにはないが定番リストにあるカード。 |
| 前回価格 | 発注なしカードに使う、最後に読めた元価格から計算した価格。 |
| 掛け率 | 元価格の増減率。`-2.7%`は値引き、`+5%`は上乗せ。 |
| 金額帯 | 特定の元価格範囲だけ別ルールを適用する設定。 |
| テンプレート | 見た目・価格ルールをまとめて保存したもの。 |
| ブラウザ固定 | 初回ログインしたブラウザプロフィールだけに使わせる安全機能。 |

## 問い合わせ時に送る情報

管理者・運営担当へ連絡するときは、パスワードを送らず、次を伝えてください。

1. 店舗名とログインメールアドレス
2. 発生日時
3. 何をしようとして何が起きたか
4. エラー文が見えるスクリーンショット
5. 左上の `v...` バージョン番号
6. 入力タイプ（とんとん形式／Vault形式）と対象ジャンル
7. Excelのシート名・ヘッダー行
8. ブラウザ固定なら、旧PC・新PC、ブラウザ名、プロフィール変更・Cookie削除の有無
