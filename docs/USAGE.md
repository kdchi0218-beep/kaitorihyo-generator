# とんとん 買取表ジェネレーター 取扱説明書

買取表（PSA10等）の画像を、毎日のExcelデータから作成するツールです。

URL: https://tonton-kaitori-generator.vercel.app/

## 1. ログイン・店舗

- 管理者が発行したメールアドレスと初期パスワード（12文字以上）でログインします。招待メールは使いません。
- **初回にログインしたブラウザへ固定**されます。以後は同じブラウザ・同じプロフィールで利用してください。
- 店舗ユーザーは自店のみ、管理者は全店舗を操作できます。定番リスト・テンプレートは同じ店舗内で共有されます。

## 2. 毎日の基本の流れ

1. 入力タイプを選び、Excelを画面にドラッグします。
   - **とんとん形式**: `🐽トントン_買取表管理_v2` から出力したポケモン/ワンピースの単一シート
   - **Vault形式**: 5ジャンルを含む1ファイル
2. ジャンルタブを選びます。
3. 定番リストを選び **「適用」** します。
4. 必要に応じてカードの追加・削除・並べ替え・価格修正をします。
5. **「PNG保存」** または **「CSV出力」** で出力します。複数ページはZIPで保存されます。

## 3. カード選択・並べ替え

| 機能 | 説明 |
|---|---|
| 選択中タブ | 買取表に載るカード。ドラッグまたは▲▼で並べ替え |
| ☑複数まとめて移動 | 複数選択したカードを、順番を保ったまま移動 |
| 未選択タブ | クリックで追加。チェックした複数カードを一括追加も可能 |
| プレビュー直接並べ替え | プレビューのカードを直接ドラッグして移動（ページまたぎ可） |
| リスト外のみ表示 | 今日のExcelで新しく見つかったカードを確認 |
| ダブルクリック編集 | カード名・価格を直接編集。価格は文字でも可 |

手動で変更した価格は、掛け率を変更しても上書きされません。

## 4. 定番リスト

毎日使うカードの順番を保存する機能です。照合は「型番＋種別＋カード名」（遊戯王はレアリティも）の完全一致です。

- **適用**: 保存順に今日の価格で展開します。在庫切れはスキップします。
- **中身を編集**: 追加・削除・並べ替えを行い、保存します。
- **選択中を追加**: 現在選択しているカードの差分だけを追加します。
- **選択中で上書き**: リスト全体を現在の選択に置き換えます。
- **Excelに無いカードを手入力で追加**: 新弾などを事前登録できます。
- **CSV**: リストの内容・在庫・前回価格を出力します。
- **他店へ送信**: リストまたはテンプレートを別店舗へコピーします。

## 5. 発注が来ていないカード

**「発注が来てないカードも表示する」** をONにすると、リスト順の位置に前回価格で表示します。画面には「前回価格」バッジが出ますが、出力画像には入りません。一度も発注データにないカードは「-」表示です。

## 6. Excelに無いカードの事前登録

1. 定番リストで **「＋ Excelに無いカードを手入力で追加（事前登録）」** を押します。
2. カード名（必須）、型番、種別、レアリティ、表示価格、画像URLを入力します。
3. リストへ追加して保存します。

カード名・型番はExcelの表記と完全一致させてください。後日Excelに載ると、そのデータへ自動で切り替わります。

## 7. テンプレート・見た目

テンプレートでは見た目と価格ルールをジャンルごとに保存できます。掛け率、定額調整、端数処理、背景、ロゴ、グリッド、カード枠、PSAバッジ、文字、更新日時、フッターなどを調整できます。

## 8. 出力

- **PNG保存**: プレビューと同じ画像を高解像度で保存します。
- **CSV出力**: 現在表示中の買取表を、表示順・価格・発注状況・前回価格付きで出力します。

画面専用の表示（前回価格バッジ、ドラッグ中の表示など）は画像に入りません。

## 9. 困ったとき

| 症状 | 対処 |
|---|---|
| 「別のブラウザに固定されています」と表示される | Cookie削除、シークレット/別プロフィール、PC交換でも同じ表示になります。管理者に **「ブラウザ登録を解除」** を依頼し、解除後にこのブラウザでパスワードログインしてください。 |
| 管理者が自分のブラウザを変えた | 別の管理者に解除を依頼してください。管理者を最低2人にして運用します。 |
| 表示がおかしい | Cmd+Shift+R（Windows: Ctrl+F5）で強制再読み込み |
| 画面上部に新バージョンの案内が出た | **「今すぐ更新」** を押す |
| リストを確認したい | 「CSV」でダウンロードしてExcelで確認 |
| 不具合を報告したい | サイドバー下のバージョン番号、スクリーンショット、操作手順を添える |
